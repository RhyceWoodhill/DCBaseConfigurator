3  Import IPs

    


      
Method A — ordered paste

      

        Copy a single multicast address column and paste below — one IP per line, in the same top-to-bottom order as the Connectors table (Streams & connectors page). Fills the IP address column only.
      

      
      

        
      


      
Method B — customer spreadsheet import

      

        Select the whole table in Excel (header row + one row per physical output: Video Primary/Backup, Audio Primary/Backup Group 1-4, Anc Primary/Backup, plus a Physical Output or Logical Output column) and paste it below. Matches rows by output number automatically — make sure you've generated the right number of outputs and audio-per-video on the Streams & connectors page first. Input rows are left blank for you to fill in later (e.g. once NMOS pushes them), or manually if you prefer.
      

      
      

        
      


      
Method C — import an existing dc_routes.json

      

        Paste (or drop) a previously-deployed dc_routes.json to pull its addresses back in
        — useful when a customer changes the audio grouping (e.g. 4 streams of 4 → 2 streams of 8)
        and you need to carry the existing addresses over instead of retyping them. It reads the address
        already active at the start of each new group and drops whichever old ones no longer have a slot.
        Set "Audio streams per video" on the Streams & connectors page to the new count and click Generate Streams
        before importing, so the rows it's filling in already match the new layout.
