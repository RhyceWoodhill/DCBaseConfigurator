Per-server settings pinned values override the baseline

Pick a server in the rail to see and edit its own config. The [System], features.conf and Linux services values on Baseline settings apply to every server; change a value here to pin it for just this one (amber, ↺ puts it back on the baseline; pinned values stay put if the baseline changes later). Color space, transfer, bit rate, proxies, codec, video standard and audio channels are global only (greyed out). The server you pick is also the one shown in the install preview.
